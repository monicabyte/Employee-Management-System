
# Employee Management System

A simple and professional Employee Management System dashboard built using HTML, CSS, and JavaScript.

## Features

- Dark-themed dashboard
- Add new employees
- Edit employee details
- Delete employee records
- Search employees
- Total employee count
- Department overview
- Save employee data using browser Local Storage
- Responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
